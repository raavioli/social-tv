# External API Shared PRD

## Overview

External API Shared is a package providing shared types, utilities, and contracts for integrating with external APIs (Twitter, Instagram, YouTube, LinkedIn, etc.) in the AI TV News system.

## Purpose

Provides standardized interfaces for external API clients, request/response contracts, OAuth flows, and data transformation utilities used across the codebase.

## Key Features

- External API type definitions
- OAuth integration contracts
- API request/response interfaces
- Platform-specific utilities
- Authentication and credential management

## Architecture

The package defines the contract layer between internal services and external API providers, enabling consistent integration patterns across the system.
